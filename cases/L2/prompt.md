# L2｜看视频后用代码复刻

照着这条抖音视频复刻一支一样的：https://www.douyin.com/video/7685931514080595200

画面全部用代码做，不调用视频生成或图片生成模型，不要声音。

先看视频，拆成逐镜规格给我确认：每个镜头的起止时间、画面、屏幕文字、镜头怎么动、怎么过渡、配色。确认后再做。规格中区分观察到的事实和推测，无法访问链接时索取原片，不要编造视频内容。

做好后，在原片和成片同一时间点各抽一帧，并排给我看。对照应覆盖关键转场及首尾，记录时间点和差异。

视频和对照文件放 `outputs/<run_id>/`，最终视频为 `videos/<run_id>_v1.mp4`。只将本文件和参考链接给被测模型，验收说明留给评测方。
