# 用例 prompt 模板

用自然语言描述「要生成什么视频」，不要直接指定技术栈（除非客户要求），让模型自己选实现方式（manim / p5.js / ffmpeg / HTML+CSS）。

## 风格与节奏

- 视觉风格（扁平/极简/科技感/手绘）：
- 节奏（每秒信息量、是否有转场）：
- 参考素材（若提供，模型应按参考图/音频对齐，不得凭空改风格）：

## 输出硬约束

- 时长 15s，1080x1920，30fps，mp4
- 所有画面文字必须清晰可读
- 不出现第三方水印/logo/版权字体

## 交付要求

- 给出完整可运行代码（单一入口，含依赖安装说明）
- 说明生成流程（渲染命令 → 输出文件名）
- 输出文件命名：`<run_id>_v<N>.mp4`
