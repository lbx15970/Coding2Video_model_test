# P3｜给一个网站链接，直接做宣传片

我的网站是 https://flova.app；品牌名 Flova，logo 使用网站上的；片尾第一句 `See it.`，斜体小尾巴 `make it in Flova.`；不要配乐。先打开真实网站，记录访问时间和地址，取真实页面、图片与 logo。访问失败时报告缺项，不能虚构页面。

做一支 14.5 秒、1440×1152、60 fps 的 3D 飞越片。页面平放在明亮影棚地面上，中央背景 #f9fbfb、四角 #f2f3f6；页面圆角 24px，四周有柔和宽阴影。

镜头一镜到底，从 hero 区低处开始，以稳定速度沿页面向后飞过并回望页面；随后升到正上方，俯视整页长条，再俯冲 hero，将其落成片尾卡。近镜头处有明显景深虚化。页面卡片略微浮起，图片、chips 和 testimonial 随镜头经过立起朝向镜头。四块小 logo tile 在 hero 按钮旁升起，陪伴到片尾。标题使用 Geist 500，斜体小尾巴使用 Instrument Serif。

先补齐文档原长 prompt 的未读细项，给出真实素材清单、镜头路径和关键帧确认，再开始整片。最终画面以固定时间决定，输出 870 帧；无音频。保存到 `outputs/<run_id>/videos/<run_id>_v1.mp4`。
