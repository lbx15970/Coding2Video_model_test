# L1｜看视频学会方法

看这条抖音视频，学会里面教的做视频方法：https://www.douyin.com/video/7655995367103679753

看完给我一张学习卡：

1. 讲了什么，属于哪一类：单个 skill、skill 组合、场景推荐、方法、通用 prompt 模板、效果模板、风格库、单项技巧。
2. 方法步骤按作者顺序；屏幕出现的提示词逐字抄下来，看不清的字标出来。
3. 用到的模型、工具、skill 和仓库。
4. 方法完不完整；作者说要进群、私信才给的，照实写。
5. 在 Flova 里能不能做：纯代码、要生成额度、要我自己的素材，还是要专业软件。
6. 怎么试：给 1–3 个具体做法。
7. 整理成可直接发给 Agent 的指令：作者写给 Agent 的话不改，写给人看的说明改成对 Agent 说；步骤、顺序、参数保留，最后加上开始前要问什么、哪里停下等我确认。

视频里没有的写「视频里没有」。链接无法访问时报告访问障碍并索取视频文件；不要假装看过。此 case 只交学习卡和指令，不执行所学的生成任务。输出到 `outputs/<run_id>/logs/<run_id>_learning_card.md`。
