# K1｜给口播加信息卡包装

帮我把 `assets/refs/K1_speech.mp4` 包装成知识类信息卡视频，`assets/targets/K1_reference.mp4` 是目标风格。按下面六步做，每一步做完停下给我看，我说可以再做下一步。

1. 分析目标视频的比例和构图、人物位置、字幕和信息卡位置、颜色系统、标题/摘要/事实卡/图表层级、动效出现顺序、节奏，以及哪些值得复用、哪些不适合照搬。总结成可复用的包装规则。
2. 对口播做语音识别和内容拆解，先不要剪完整视频。每个信息段输出：口播大意、左上大标题、副标题或重点句、一句摘要、三个事实卡、右侧图表或二维动效、对应的参考包装方式。信息卡表达这段话真正的逻辑，不是逐字字幕。
3. 先做 3–5 张关键帧预览，不渲染完整视频。横版 16:9，包含左上大标题、左中摘要条、左下事实卡、右上图表，以及左上和左下之间的小信息层。不要挡住人物脸部中轴，主标题清晰、层级明确、配色统一。
4. 关键帧确认后，只渲染 15–25 秒样片。标题先出现，摘要条随后滑入，事实卡逐张弹出，右上图表最后出现；图表里的线条、柱状和数字有动画，数字从初始值变化到目标值。等各主信息层建立后再出现中间小信息层。吸收参考片的推进节奏，不让所有元素一起出现。
5. 到这一步时，只修改以下内容：右侧图表再往右，不挡脸；事实卡弹出再慢一倍；所有蓝色图标和色块改成黄色；中间小信息层提前出现；不加底部字幕；保留大标题，重新设计卡片；拉开图表出现顺序。其他内容保持不变。
6. 修改后的样片确认后，渲染完整视频：1920×1080，保留原声，沿用已确认的视觉系统与动效节奏。抽取开头、中段、结尾关键帧，检查画幅、遮脸、文字溢出、配色、动效顺序，以及信息卡是否真正提炼了逻辑。

片长随原片，帧率先确认。缺少素材时先列出缺项。所有产物放 `outputs/<run_id>/`，最终视频为 `videos/<run_id>_v1.mp4`。
