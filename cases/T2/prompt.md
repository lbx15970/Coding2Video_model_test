# T2｜七段式中文竖屏教程

主题是「在 Flova 里一键装好灵感库里的 skill」，希望观众记住「看到的 skill，点一下就装好」；30 秒、1080×1920、30 帧；界面动效；主色 #2F6BFF，思源黑体；用代码合成配乐，不要配音。

<role>
你是一位动态设计师，也是一位创意程序员，擅长用代码做出有设计感的视频。
</role>

<inputs>
开工前确认主题与希望记住的一句话、时长与画幅帧率、风格和参考、配色字体、声音与配音。上面已给的信息不要重复索要；未给的不要编。缺少字体或不理解下面的截断句时，先问清处理方式。
</inputs>

<direction>
整片只用一套风格、一套配色，同一个角色或元素在每个镜头里的样子都要一致。
每个镜头只讲一件事，画面上的字少而大，每段文字至少停留 2.5 秒。
动画用缓动或弹簧，不用匀速运动。转场从画面内容里长出来，比如一条线变成下一个场景的地平线，不用…[画面截断]
镜头要跟着内容动，推近、拉远、跟随，让主体在画面里足够大。
禁止：【居中大字加渐变背景的默认风格、所有元素同时淡入、满屏小字、任何看起来像模板的东西，按你…[画面截断]
</direction>

<structure>
先写分镜表，每个镜头写：镜头编号、开始结束秒数、画面构图/元素/文字、进场/主动作/出场、镜头推拉跟随或固定、音乐与音效、到下一镜头的转场。
如果有音乐，先分析节拍，镜头切换和关键动作都落在拍子上。
</structure>

<build>
1. 画面用【Canvas 2D / HTML+CSS+SVG / WebGL 着色器 / Three.js / Remotion…[画面截断]
2. 页面暴露 window.render(t)，画出第 t 秒。所有画面只由 t 算出来，随机数带固…[画面截断]
3. 用 Playwright 逐帧调用 render(t) 并截图，再用 ffmpeg 合成 MP4。
4. 配乐和音效用 Python（numpy、scipy）从零合成，每个音效放在画面动作发生的…[画面截断]
5. 每做完一个镜头，先渲 3 张静帧自己检查：文字有没有溢出、元素有没有重叠、画面…[画面截断]
</build>

<gotchas>
- 字体加载完再开始截图，不然前几帧会用默认字体。
- 用了 WebGL 的话，先渲一帧确认着色器真的生效了，再渲整片。
- 你听不到声音，所以要把音频的波形画成图自己检查，确认没有爆音。
</gotchas>
