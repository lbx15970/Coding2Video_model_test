# 评测规则

每次 run 的结论统一按下面维度打分，报告写到 `evals/reports/<run_id>.md`。

## 硬性门槛（任一不过直接判 fail）

1. 视频能正常播放，时长/分辨率/fps 符合 `case.yaml` 的 `output_spec`。
2. `must_have` 信息点全部出现且文字无错别字。
3. 无第三方水印、无版权素材、无敏感内容。
4. 代码可复现：按 README 说明能重新渲染出同样的视频。

## 打分维度（1-5 分）

| 维度 | 看什么 |
|---|---|
| 内容准确性 | 信息点是否对、是否有幻觉 |
| 视觉质量 | 构图、配色、字体层级、清晰度 |
| 节奏 | 单位时间信息量、转场是否自然、有无空镜过长 |
| 参考还原度 | 有参考素材时，风格/节奏是否对齐 |
| 代码质量 | 结构、依赖、可运行性、改造成本 |
| 稳定性 | 同 prompt 多次跑的结果方差 |

## 结论写法

在 `runs/RUNS.md` 的「结论」列写一行结论，形如：
`pass 4.2/5 | 优于 baseline 12% | 问题：结尾 2s 空镜过长`
